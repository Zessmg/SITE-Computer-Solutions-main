Conexión Node.js + Supabase SQL Schema

Para conectar esta aplicación a tu propio proyecto de Supabase:

  1. Crea un proyecto en Supabase.com.
  2. Abre el SQL Editor en tu consola de Supabase.
  3. Copia y ejecuta el contenido del archivo schema.sql generado en el proyecto.
  4. Pega tus variables SUPABASE_URL y SUPABASE_ANON_KEY en el archivo .env.
